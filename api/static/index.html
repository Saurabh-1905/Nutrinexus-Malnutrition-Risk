Why these signals matter

Child malnutrition can't be read from a single number.

Growth, weight, food supply, income and basic services are interconnected. A country may look similar on one measure and very different on another, so NutriNexus looks at several population-level signals together.

Methodology

How NutriNexus works

1. Dataset

A country-year table of 272 records covering 59 countries, with reference years from 1988 to 2023. It combines child anthropometric indicators (stunting, wasting, underweight) with FAOSTAT context variables such as undernourishment, GDP per capita (PPP), and basic drinking-water and sanitation access.

2. Country-year structure

Each row is one country in one reference year. Every row is paired with the following year, and countries differ in how many years they have, so the prediction page offers only the years each country actually has.

3. Target definition

The overall risk score is the average of stunting, wasting and underweight. The target is that score for the following year, grouped into three classes: Low, Moderate and High (92, 93 and 87 records respectively).

4. Feature preparation

The model receives 35 input features: current indicators, FAOSTAT context, and history-based features such as previous values, year-to-year changes and rolling averages. Missing values are filled with the median, and missingness indicators are added.

5. Feature selection

A selector fitted on training data only keeps the 30 most informative transformed features, so nothing from the test period influences the selection.

6. Random Forest model

A Random Forest of 500 trees (max depth 8) with balanced class weights. The trend model was weaker (about 57.78% test accuracy) and is not deployed here.

7. Chronological evaluation

Records are ordered by time, so validation always tests on later data than it trained on. Time-aware cross-validation accuracy is 88.89% ± 6.09%.

8. Future test evaluation

Training used 227 records. The final test used 45 later records (cutoff 2018): 42 correctly classified, for 93.33% accuracy, 92.19% balanced accuracy, 92.67% macro F1 and 97.99% macro ROC-AUC. Training accuracy is 99.56%, so some overfitting is expected, and the small test set means these results carry real uncertainty.

9. Limitations

  • The model works at country-year level. It is not an individual-child diagnosis tool and gives no medical advice.
  • It estimates a category for the year after the selected reference year, only for country-years in the dataset. It cannot predict arbitrary years.
  • Small test set (45 records) and uneven country coverage.
  • Labels come from the dataset's own score, so accuracy reflects agreement with that definition.

Data sources

Context indicators (undernourishment, GDP per capita PPP, drinking-water and sanitation access) come from FAOSTAT, Food and Agriculture Organization of the United Nations. Stunting and wasting come from the Joint Child Malnutrition Estimates (JME) by UNICEF, WHO and the World Bank. Underweight comes from the WHO Global Health Observatory (GHO). The three were combined with the FAOSTAT variables into one country-year dataset.

About

About NutriNexus

NutriNexus is a personal B.Tech CSE (AI & Data Science) project exploring how machine learning can be used to analyze global child malnutrition patterns.

This system operates at the country-year level and is not an individual-child medical diagnosis tool.

The project title is “Child Malnutrition Risk Prediction Using Global Country-Year Data and Machine Learning”. The source code is on GitHub.
